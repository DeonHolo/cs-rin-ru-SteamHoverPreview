# CS.RIN.RU architecture

The public root [csrinruSteamHoverPreview.user.js](../../csrinruSteamHoverPreview.user.js) is generated by scripts/build.mjs. The script's install identity remains intact; the userscript header is maintained in src/userscript-header.txt.

## Source ownership

| Module | Responsibility |
| --- | --- |
| src/core / steam-client.mjs | Official reviews, storefront details/search/tags, confidence and DLC resolution, corrections, field cache, request priority/retry/cancellation |
| Shared preview.mjs | Escaped card rendering, tags-first readiness, independent row updates, correction UI, SVG icons, media/theatre, keyboard/focus and viewport handling |
| Shared runtime.mjs | GM legacy/modern wiring, ready-state bootstrap, nearby/full/hidden preload, userscript menus/settings, diagnostics |
| Shared site-utils.mjs | Bounded same-origin source-page requests and scoped Steam-link extraction; Enhanced tag colours belong to the CS.RIN adapter |
| [src/adapters/csrinru.mjs](../../src/adapters/csrinru.mjs) | Topic identity/sections, forum labels/status tags, latest-post/page selection, first-post Steam-link lookup, dark defaults |
| scripts/build.mjs / sync-core.mjs | Dependency-free standalone build and version/hash-locked shared-source distribution |

This repo is the canonical shared source. The companion 1337x repository pins a snapshot of the same core and tests.

## Runtime path

The adapter returns a stable site item key, raw title, cleaned title, source URL, and site utilities. The engine resolves a confident base AppID or a validated saved correction; query aliases reuse AppID metadata. The controller waits for actual tags or a bounded unavailable state before its first meaningful card. Reviews use a lower-priority independent request and only replace their own row. Hover generations and per-consumer cancellation prevent old responses from altering a newer game.

Preload uses the same loadPreview pipeline as hover, so it warms actual tags rather than saving genres. Shared request jobs promote active hover consumers, deduplicate resource requests, cap concurrency, respect hidden state and cooldowns, and abort when abandoned. Cache clearing uses a generation and cross-tab clear epoch; reset markers prevent stale correction resurrection.

## Site behavior retained and repaired

- Recognize structural topic rows and section headings, excluding announcements/stickies. Section state is recomputed rather than permanently caching one English heading result.
- Preserve proper names such as The Beginner’s Guide; administrative words alone no longer exclude a game.
- Prefer explicit last-post links; otherwise choose the greatest pagination offset. Validate same origin/topic, with explicit p-only last-post links scoped to the topic row.
- Keep AppID copy and SteamDB as distinct controls, with nonblocking clipboard/manual-copy feedback.
- Keep redundant Info suppressed, deduplicate other bracket tags, and match CS.RIN.RU Enhanced colours from raw source inline styles or its original algorithm against the source ancestor background. See [4.01 colour compatibility](Enhanced-Tag-Colors.md).
- Retain native direct-video/native-HLS capability checks and a Steam fallback; no hls.js/blob dependency is introduced.

## Tests and maintenance

Use [CONTRIBUTING](../../CONTRIBUTING.md) for actual commands and [verification](Verification-and-AI-Workflow.md) for evidence. The standalone userscript has no runtime import or package fetch. Development source imports the pinned local Fuse asset, which the build isolates inside the userscript closure. Dev dependencies provide formatting/lint and isolated browser checks only. Dynamic-site markup/permissions still require real-browser validation before publication.
