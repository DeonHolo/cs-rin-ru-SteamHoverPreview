# Changelog

## 4.05

Changes since public version 4.04.

- Recognize Disco Elysium as Disco Elysium – The Final Cut using its verified Steam identity.
- Improve edition matching so Skyrim Special Edition matches directly while original Skyrim, Special Edition and VR stay separate.

## 4.04

Changes since public version 4.03.

- Keep hover previews restricted to Topics and topic-search results; explicitly exclude Global Announcements, Announcements and Stickies.

## 4.03

Changes since public version 4.02.

- Restore Steam hover previews on forum topic search results, including highlighted game titles.

## 4.02

Changes since public version 4.01.

- Move Wrong game? to the right of the game title, keeping Open on Steam at the bottom-left.
- Allow long game titles to wrap beside the correction button, including on narrow screens.

## 4.01

Changes since public version 4.00.

- Restore forum-tag colours to match CS.RIN.RU Enhanced, including CRACKED, Early Access and VR Optional, in matched and failed previews.
- Replace the SteamDB shortcut’s external-link arrow with a small SteamDB logo beside the AppID.

## 4.00

Changes since public version 3.2.

- Show actual Steam tags in the first useful preview, without temporary genre replacements or needing a second hover.
- Improve preview loading and cached repeat hovers, with priority for the game you are browsing.
- Repair Steam review retrieval, including recently released games, and show clearer no-review and unavailable states.
- Improve title matching for typos, punctuation, release suffixes, commercial editions and localized names; follow verified DLC links to the base game.
- Search by name inside Choose Steam game… or Wrong game?, select from closest-name suggestions, and save the correct game for future visits. AppID and Steam URL entry are also available.
- Add a Settings entry in the userscript manager’s extension menu for nearby/page/on-hover preloading, preview theme and review filtering, plus tools to manage saved matches and cached data.
- Improve keyboard access to previews and focus handling during actions.
- Use a small Steam logo for the store action.
- Improve forum topic detection and selection of the latest post/page link.
